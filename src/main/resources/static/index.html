    开始之前，了解这些

    迁移的是歌单与歌曲引用，不是音频文件。

    QQ 音乐

    公开歌单免平台登录读取。私有歌单、创建歌单与加歌需要有效 Cookie；平台风控可能影响写入。

    Apple Music

    需要配置开发者令牌并完成用户授权。确认迁移后，新歌单写入你的 iCloud 音乐资料库。

    网易云音乐

    仅支持 QQ 到网易云。真实连接使用服务器运行用户已登录的本机 CLI，只在单机部署可用；公网部署走演示授权。

    同一首歌可能有不同版本。请核对匹配结果中的歌手、专辑和 Live / Remix 提示；如果写入结果不确定，先检查目标歌单，不要重复提交。

    TuneBridge 音桥

    仅用于个人歌单备份迁移，不提供下载或版权绕过能力。请遵守各平台服务条款。

    连接平台

    选择演示授权或真实账号

    演示授权

    使用内置曲库，不访问真实账号；请同时使用演示来源。

    或使用真实账号
    如何获取 QQ 音乐 Cookie？
    1. 在浏览器登录 y.qq.com；
    2. 按 F12 打开开发者工具，切换到 Network；
    3. 刷新页面，点击任意一个 y.qq.com 请求；
    4. 在 Request Headers 中找到 Cookie，复制整段值粘贴到上方。

    Cookie 的有效期由平台决定。音桥只把 Cookie 存在当前会话内存中。

    将打开 Apple 授权窗口，完成后自动返回音桥。

    手动粘贴 Music-User-Token

    真实模式使用服务器运行用户已登录的本机 CLI，并非多用户账号授权。配对码由本机操作员设置，不是平台 Key 或 Secret。

    断开音桥连接不等于退出 CLI；CLI 的账号状态可能保存在服务器本机。

    请勿向他人透露凭据或配对码。网易云 CLI 登录状态可能保存在服务器本机，断开音桥连接不会退出 CLI。
