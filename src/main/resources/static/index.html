UNDER THE HOOD

每一步都有迹可循。

连接、读取、搜索、匹配、写入；演示模式不触达真实账号。

01

连接目标平台

Apple Music 通过 MusicKit 授权，QQ 音乐通过 Cookie 连接。网易云真实模式使用服务器运行用户已登录的本机 CLI，不是多用户授权。

02

逐首智能匹配

标题、歌手、专辑综合打分，兼容中英文、标点与 Live/Remaster 版本差异，低置信结果单独标注。

03

写入并生成报告

在目标平台创建新歌单、分批写入匹配歌曲，并输出成功 / 未匹配 / 低置信的逐首迁移报告。

REAL INTEGRATION

真实接入，也保留体面的降级。

Apple 开发者令牌或网易云本机 CLI 未配置、或 QQ 写接口触发风控时，音桥会明确提示。演示模式用于体验与展示。

QQ 音乐

公开歌单直接读取；创建歌单与批量加歌需要有效 Cookie。

Apple Music

需要开发者令牌 + 用户授权；写入发生在你的 iCloud 音乐资料库。

网易云音乐

仅作为 QQ 的目标，真实模式使用服务器运行用户已登录的本机 CLI；账号状态可能保存在本机。

TuneBridge 音桥

仅用于个人歌单备份迁移，不提供下载或版权绕过能力。请遵守各平台服务条款。

如何获取 QQ 音乐 Cookie？
  1. 在浏览器登录 y.qq.com；
  2. 按 F12 打开开发者工具，切换到 Network；
  3. 刷新页面，点击任意一个 y.qq.com 请求；
  4. 在 Request Headers 中找到 Cookie，复制整段值粘贴到上方。

票据通常 3 天左右过期。音桥只把 Cookie 存在当前会话内存中。

将打开 Apple 授权窗口，完成后自动返回音桥。

手动粘贴 Music-User-Token

真实模式使用服务器运行用户已登录的本机 CLI，并非多用户账号授权。配对码由本机操作员设置，不是平台 Key 或 Secret。

断开音桥连接不等于退出 CLI；CLI 的账号状态可能保存在服务器本机。

请勿向他人透露凭据或配对码。网易云 CLI 登录状态可能保存在服务器本机，断开音桥连接不会退出 CLI。
